# Java Movie Picker (Randomized)

A basic program that picks movies from a built in list, and allows the user to add movies of their own. They can also choose movies that they have either not marked as seen before,
or a few other combinations. Not too many though

## Instructions for Build and Use

Steps to build and/or run the software:

1. Have VSCode installed
2. Have Java installed
3. Install VSCode extensions for Java
4. Run the program with the run button in the top right corner

Instructions for using the software:

1. When running the program, and type any number from 1-8 to select an option
2. As prompted, enter valid strings for movie titles
3. Otherwise, navigate through the varied selection until you wish to exit
4. Exit the program with 0

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

- Visual Studio Code
- Java version 1.8.0_471 (or newer)
- A downloaded copy of both Main.java and Movie.java (current versions)
