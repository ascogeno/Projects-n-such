# Parody Scam WebApp

This is just a simple WebApp that pretends to pull technical info about the user from some basic user input. The info it pulls is, in reality, randomly generated.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Copy the github Repo
2. Open the cloned repo into VSCode
3. Ensure Python is installed
4. Ensure Django is installed
5. Ensure Pip is installed, otherwise Django won't install
6. Ensure you don't have two installations of Python. The older version will be prioritized when running python files and will make you wonder if you should be in the CS field for somehow finding a way to make Python files fail to run
7. Open DjangoTutorial into an integrated terminal
8. run "py manage.py runserver"
9. Ctrl Click the server link to open the website into your default browser

Instructions for using the software:

1. Upon opening the site, enter valid information into the text boxes
2. If you wish to test error handling, enter invalid information into the the text boxes
3. Once valid information is entered, submit and view the generated results
